# Web Restic UI 原型设计

> 版本：v0.1（设计稿）
> 配套文档：《需求分析设计》`requirements-design.md`、《系统概要设计》`system-design.md`
> 技术底座：Vue3 + TypeScript + antdv（vben 工程既有骨架）

## 1. 设计规范

### 1.1 整体布局

沿用 vben 基础布局（`layout-basic.vue`）：

```
┌──────────┬────────────────────────────────────────────────┐
│  侧边菜单   │  顶栏（面包屑 / 全局搜索 / 主题 / 用户）                │
│          ├────────────────────────────────────────────────┤
│  菜单树    │  多页签 Tabs（可关闭、右键操作）                       │
│          ├────────────────────────────────────────────────┤
│          │                                                │
│          │              内容区（router-view）                │
│          │                                                │
└──────────┴────────────────────────────────────────────────┘
```

### 1.2 菜单与权限映射

| 一级菜单 | 二级菜单 | 路由 | 权限 | 说明 |
| --- | --- | --- | --- | --- |
| 工作台 | — | /dashboard | read | 统计卡片 + 最近执行 |
| 存储仓库 | — | /repos | read（操作按钮按 write/admin 显示） | 仓库 CRUD、连接测试 |
| 主机管理 | — | /hosts | read（操作按钮按 write/admin 显示） | 主机 CRUD、SSH 测试 |
| 备份任务 | 任务列表 | /tasks | read（操作按钮按 write/admin 显示） | 任务 CRUD、启停、手动执行 |
| 备份任务 | 执行记录 | /tasks/runs | read | 全部执行记录 |
| 备份数据 | 快照列表 | /snapshots | read（恢复/清理按 write 显示） | 快照、文件树、恢复、清理 |
| 系统管理 | 用户管理 | /sys/authority/user | admin（已有） | 用户 CRUD |

> 权限沿用前端既有 `permission` 插件与后端 `auth.Require` 双端校验；无权限的菜单项不渲染。

### 1.3 通用交互约定

- **列表页**：搜索区（折叠）+ 工具栏（刷新 / 新增）+ 数据表格 + 分页；行操作：详情 / 编辑 / 删除 / 更多。
- **表单**：抽屉（Drawer，宽 520px）承载，复杂表单（任务）用向导（Steps）。
- **危险操作**（删除仓库/主机/任务、forget 快照）：`Modal.confirm` 二次确认，输入名称或勾选确认。
- **敏感字段**（密码/私钥）：输入框 `password` 类型 + 眼睛切换；回显一律 `******`，编辑时留空表示不修改。
- **状态色**：success=绿 / running=蓝(loading) / pending=灰 / failed=红 / error=红 / disabled=灰。
- **空态/加载/错误**：表格空态插画 + 说明；操作按钮 loading 防重复提交；接口失败 antd message 提示并保留现场。

## 2. 页面原型

### 2.1 登录 / 注册（已有，微调）

```
┌──────────────────────────────┐
│          logo  Web Restic      │
│  ┌────────────────────────┐   │
│  │ 用户名  [____________]  │   │
│  │ 密码    [____________]  │   │
│  │  [  登  录  ]           │   │
│  │  没有账号？去注册         │   │
│  └────────────────────────┘   │
└──────────────────────────────┘
```

- 登录成功：保存 `{data:{token,expiresAt,user}}` 到本地存储，跳转工作台。
- 注册：用户名/密码/确认密码；提示"首个注册用户为管理员"。
- 开发环境保留 `/api` 前缀代理，登录走 `POST /api/auth/login`。

## 3. 组件与复用建议

| 组件 | 用途 | 说明 |
| --- | --- | --- |
| `StatusTag` | 状态展示 | 统一映射 状态→颜色/文案/loading 图标 |
| `RepoTypeSelect` | 仓库类型选择 | 联动凭据字段显隐 |
| `CronInput` | cron 表达式输入 | 文本 + 常用预设（每日/每周/每月） |
| `PathListInput` | 源/排除路径多值输入 | 带增删行与校验 |
| `KeepPolicyForm` | 保留策略表单 | 勾选式 keep-* 字段 |
| `RunLogViewer` | 执行日志查看 | SSE 订阅 + 自动滚动 + 复制/下载 |
| `SnapshotTree` | 快照文件树 | 懒加载目录树 + 多选恢复 |
| `SensitiveInput` | 敏感字段输入 | 掩码展示、密码切换、留空不修改语义 |
| `ConfirmModal` | 危险操作确认 | 二次确认 + 输入名称校验 |
